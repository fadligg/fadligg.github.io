Mengapa Vocalet Diciptakan?

Kesenjangan Aksesibilitas
Aplikasi keuangan saat ini sangat mengandalkan interaksi layar sentuh dan teks kecil. Ini menjadi dinding penghalang besar bagi penyandang tunanetra dan kelompok lanjut usia.
Pencatatan UMKM Tradisional
60% pelaku usaha mikro masih mencatat di buku tulis. Rentan hilang, sulit dilacak, dan mustahil menghasilkan laporan keuangan (Laba/Rugi) yang rapi untuk pinjaman modal.
Literasi & Perhitungan Zakat
Banyak umat muslim bingung mengenai perhitungan Nisab dan persentase zakat dari harta campuran, sehingga pembayaran zakat sering terlewat atau tidak akurat.
Solusi Vocalet 💡
Menjembatani kesenjangan tersebut melalui teknologi Natural Language Processing (NLP). Pengguna cukup berbicara seperti kepada asisten manusia, dan AI kami akan mengklasifikasikan ucapan menjadi struktur data finansial (JSON) yang terstruktur di database.

Value Proposition Utama

Zero-Touch Interface
Input data pemasukan, pengeluaran, hingga pembuatan laporan murni melalui perintah suara tanpa perlu navigasi menu yang rumit.
Desain Inklusif
Didukung kontras tinggi, typography ekstra besar, dan dukungan Screen Reader. Fitur Text-to-Speech membacakan ulang aksi ke pengguna.
Auto-Zakat Calculator
Algoritma otomatis mendeteksi apakah total aset/penghasilan sudah mencapai ambang batas (Nisab) dan menghitung nilai zakat aktual.
Ekosistem UMKM
Bukan sekadar pencatatan pribadi, tapi mendukung manajemen multi-produk, tracking stok masuk/keluar, hingga data supplier.
Midtrans Integration
Dukungan pembayaran digital instan melalui generate QRIS dinamis, e-Wallet, dan Virtual Account untuk transaksi UMKM.
Keamanan Data
Autentikasi berlapis menggunakan Laravel Sanctum Token, enkripsi password bcrypt, dan perlindungan API rate limiting.

Arsitektur Sistem (Voice-to-Database)

1. User Input
Suara ditangkap oleh Mic (PWA)
2. Web Speech API
Speech-to-Text di Frontend Next.js
3. Gemini AI Engine
Backend Laravel kirim teks ke AI utk ekstraksi entitas (JSON)
4. Eksekusi & Simpan
Validasi logic & insert ke DB MySQL
*Response dari server kemudian diubah kembali menjadi suara melalui Text-to-Speech (TTS) API untuk mengonfirmasi tindakan kepada pengguna.
